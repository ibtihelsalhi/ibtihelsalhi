## Featured project

**Smartovate CyberAgent** : a security automation platform that aggregates findings from **GitHub, AWS and Azure**, then normalizes, correlates, deduplicates and prioritizes them (MITRE ATT&CK, CIS Benchmarks). FastAPI backend (35 REST endpoints, PostgreSQL, JWT, MFA, RBAC), analyst-approved remediation through GitHub pull requests, deployed with Docker, Bicep and Azure Container Apps.
